01 / Service

A narrow service for the work that sits between a client spreadsheet and a safe import.

Built for WooCommerce migrations, rebuilds, launches and catalogue maintenance where repetitive product-data work starts eating into senior delivery time.

01

Clean

Normalise agreed fields, remove obvious formatting inconsistencies and prepare a controlled candidate file without inventing missing business decisions.

02

Check

Separate what can be corrected from what needs client or agency judgement, so uncertainty is visible rather than silently guessed.

03

Document

Return the cleaned file with a source-linked change log, exception list and a practical staging-import checklist.

03 / Scope

Fixed enough to be useful. Narrow enough to stay predictable.

Included in the £195 pilot
  • One client-supplied CSV
  • Up to 250 simple-product rows
  • One agreed field mapping
  • Catalogue cleanup and QA against agreed source rules
  • One correction round
  • Two-business-day target after usable input is confirmed
Outside the standard pilot
  • Customer, order or payment data
  • Automatic production-store imports
  • Unbounded product copywriting
  • Variable or highly bespoke product logic unless separately agreed
  • Commercial decisions where the source data is ambiguous
  • Additional source systems or mappings unless separately agreed
Data handling: The pilot is designed for product catalogue data only. Do not send customer, order or payment information. Confidential source files are accepted only after the project scope and handling method are agreed.
