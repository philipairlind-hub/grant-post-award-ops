# Grant Post-Award Ops

Public website for a founder-led post-award grant administration pilot serving UK grant-making charities, foundations, and professional foundation administrators.

## Local preview

Serve the repository root with any static web server, for example:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Hosting

The site is designed for GitHub Pages and requires no build step or runtime dependencies.
